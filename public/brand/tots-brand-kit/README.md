## Asset usage

### Web (favicon + meta)

Drop the favicon files at your web root and reference them in `<head>`:

```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16.png">
<link rel="apple-touch-icon" sizes="180x180" href="/tots-app-icon-180.png">
<meta name="theme-color" content="#C8EFD4">
```

## Clear space + min sizes

- **Clear space:** keep an empty margin equal to the height of one teddy ear around the icon on all sides.
- **Min size — icon only:** 24×24 px. Below that, switch to `tots-icon-monochrome-dark.svg` or a simplified mark.
- **Min size — full horizontal logo:** 120 px wide. Below that, drop the wordmark and use icon only.

---

## Do not

- Don't recolor the squircle background to harsh or neon colors. Keep it inside the pastel palette.
- Don't apply drop shadows or glows — the brand is flat and soft.
- Don't stretch the icon non-uniformly. Always scale proportionally.
- Don't place the color icon on a busy photographic background without a card/surface behind it.
- Don't rotate the icon. The bear faces forward.

---

## Wordmark font

The wordmark is set in **Quicksand Bold** with letter-spacing `-3` at large sizes. If you ship the wordmark as live SVG text in production, install Quicksand (Google Fonts, free) — otherwise it will fall back to `ui-rounded` / `SF Pro Rounded` / system rounded, which is close but not identical.

For guaranteed consistency across platforms, ship the **PNG wordmark** or convert the SVG text to outlines in your design tool (Figma: "Outline stroke" + "Flatten selection").
