Future product direction

Useful features and updates for Baby Tube

Baby Tube is already focused on curated YouTube videos, clip enforcement, playlist import, admin management, and a configurable screen-time timer. These recommendations aim to increase safety, parent control, and daily usefulness without losing the simple child-friendly experience.

Primary goal Make watching safer and more intentional for children.
Best first investment Replace iframe interaction with app-owned player controls.
Best product unlock Add queues, categories, schedules, and parent insights.

Recommended Features

1

Safer Player Controls

Implemented

Implemented app-owned play, pause, resume, replay, next, fullscreen, and progress controls using the YouTube Player API. The YouTube iframe is now non-interactive, reducing the risk of kids tapping external overlays or recommendations.

Safety Player High ROI
2

Content Categories

Implemented

Implemented tags such as Songs, Learning, Bedtime, Arabic, Animals, and Short Clips. The home page now shows curated sections instead of one flat list, making discovery easier for both parents and children.

Content Admin Discovery
3

Watch Queue / Playlist Mode

Implemented

Implemented a parent-managed "today's queue" from approved videos. When the queue has videos, the child only sees the selected queue, and the app auto-advances through it safely until the queue or screen time ends.

Parent control Routine Auto-play
4

Schedule-Based Screen Time

Extend the current configurable timer into daily windows, such as morning, after school, and bedtime. This supports real family routines better than a single global limit.

Timer Settings Daily routine
5

Child Profiles

Add profiles with separate timer settings, preferred categories, age ranges, and watch history. This makes the app more useful for families with multiple children or different viewing routines.

Profiles Personalization Future scale
6

Parent Dashboard

Show practical insights like watched today, screen time used, favorite videos, skipped videos, and last watched. Keep it lightweight and useful rather than analytics-heavy.

Insights Admin Trust
7

Video Health Checks

Detect deleted, private, unavailable, or duplicate YouTube videos and flag them in the admin area. This keeps the curated library reliable as imported playlist content changes over time.

Maintenance YouTube API Reliability
8

Admin UX Improvements

Add drag-and-drop ordering, search and filters, bulk category assignment, duplicate detection, and faster clip trimming. These updates make library curation much easier as the video list grows.

Admin Curation Efficiency
9

Break Mode

Implemented

When time expires, show a calm break screen with parent-approved ideas such as stretch, drink water, read a book, or bedtime. This turns the timer ending into a gentler transition.

Wellbeing Timer Child UX
10

PWA / Home Screen App

Make Baby Tube installable on tablets and phones with a home-screen icon, standalone display mode, and a more app-like child experience.

PWA Mobile Experience

Recommended Build Order

  1. Safer player controls: improve the most important safety surface first.
  2. Categories and tags: create the content structure needed for better browsing, queues, and profiles.
  3. Watch queue: let parents decide what can play during a session.
  4. Schedule-based screen time: make limits match real daily routines.
  5. Parent dashboard: add visibility once watch sessions and timer behavior are richer.
Implementation note: start with data model changes for tags, queues, and schedule settings before building larger UI flows. Keep raw API logic in lib/ or route handlers, and keep admin mutations behind the existing admin password flow.
